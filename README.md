# ComerciApp Mobile - Prototipo Funcional (MVP)

Aplicación móvil híbrida para la gestión de asistencia, inventario y métricas gerenciales desarrollada para pequeñas y medianas empresas.

## 🛠️ Tecnologías Utilizadas

- **Frontend:** Ionic Framework v7 + React
- **Lenguaje:** TypeScript
- **Herramienta de Construcción:** Vite
- **Iconos:** Ionicons
- **Control de Versiones:** Git + GitHub (Flujo GitFlow)

---

## 📱 Módulos del Prototipo

1. **Registro de Asistencia:** Reloj en tiempo real, perfil de usuario y lista de marcajes con estado de puntualidad.
2. **Control de Inventario:** Buscador por SKU/nombre, filtros por nivel de existencia y ajuste local de stock.
3. **Dashboard Gerencial:** Selector de sucursales activas, tarjetas KPI de asistencia/stock y feed de actividad reciente.
