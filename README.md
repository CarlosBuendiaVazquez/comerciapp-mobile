## Descripción del Proyecto

**ComerciApp** es una solución tecnológica híbrida diseñada para resolver la descentralización operativa y la falta de herramientas digitales accesibles en pequeñas y medianas empresas (PyMEs) con múltiples sucursales.

La plataforma conecta las distintas sucursales a una base de datos centralizada, permitiendo:
* **Control de asistencia:** Registro de entradas, salidas y retardos del personal por sucursal.
* **Gestión de inventario:** Control de stock en tiempo real con alertas automáticas de niveles mínimos.
* **Panel de reportes:** Dashboard consolidado para administradores y dueños.

---

##  Stack Tecnológico

* **Frontend Mobile:** Ionic Framework + React (TypeScript)
* **Contenedor Nativo:** Capacitor (Plugins de Cámara / QR o Geolocalización)
* **Backend & Base de Datos:** Node.js / Firebase / Supabase (PostgreSQL/NoSQL)
* **Gestión de Proyecto:** Jira Software (Metodología Kanban/Scrum)
* **Control de Versiones:** Git & GitHub
